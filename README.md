# Movie Correlation Analysis

This is a mini data analysis project using Python and Pandas.

## Objectives
- Clean movie dataset
- Handle missing values
- Explore correlations between variables
- Identify factors affecting gross revenue

## Tools
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Insight
Budget and gross revenue have a very strong positive correlation (0.93).
